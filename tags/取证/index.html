    答：8006
    首先我要先查一下pve集群是啥
    PVE = Proxmox VE
    一款开源免费的虚拟化系统，类似VMware、Hyper-V，用来在一台物理机上装多台虚拟机（Windows、Linux、取证虚拟机、渗透靶机都能跑），自带网页管理后台。
    集群（Cluster）
    把多台安装了PVE系统的物理服务器，用内网高速网线互相连通，统一管理、资源共享，这一整套组合就叫 PVE集群。
    从Chrome浏览器的历史记录里翻到了，URLhttps://pve-node01.pgscup:8006/最后是端口号
    URL到底是什么？里面为什么会有端口号？
    URL = Uniform Resource Locator
    中文：统一资源定位符
    大白话：互联网上每个资源的“详细地址”
    日常例子
     https://www.baidu.com/index.html 
    这一整条就是URL。
    资源可以是：网页、图片、视频、接口、网盘文件。
    URL标准结构拆分
    协议://域名/IP:端口/路径?参数#锚点 
    拿示例拆解：
     https://www.baidu.com:443/index.html?name=test#top 
    1. https：传输协议（http、https、ftp、ws）
    2. www.baidu.com：域名（也可以直接写IP，例如 192.168.1.1）
    3. 443：端口（https默认443，http默认80，可以省略不写）
    4. /index.html：资源路径，服务器里面文件位置
    5. ?name=test：GET请求参数，向服务器传递数据
    6. #top：锚点，页面内部跳转，不会发给服务器
